# Language Learning – App-Ordner

Wird von `werkzeuge/bauen.py` erzeugt bzw. ergänzt. Von Hand gepflegt: `app.js` (Code), `app.css` und `basis.css` (Stil). Erzeugt: `index.html`, `daten_<paar>.js`, `manifest.webmanifest`, `sw.js`, `icons/`.
Audio liegt in `audio/<paar>/…` (ElevenLabs, siehe `werkzeuge/audio.py`). `francais/` ist nur eine Weiterleitung von der alten Adresse.
Tasten am Laptop: Leertaste = Abspielen, Pfeil rechts = Weiter / Lösung, Pfeil links = Zurück.
